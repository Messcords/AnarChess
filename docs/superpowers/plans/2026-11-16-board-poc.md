# POC Plateau d'échecs 2D — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une page Nuxt qui affiche un plateau d'échecs 8×8 en 2D avec les
pièces en position de départ, déplaçables librement en deux clics, avec un
bouton de réinitialisation.

**Architecture:** Logique pure en TypeScript dans `screens/app/utils/`
(géométrie du plateau, plateau en matrice 8×8 au format `Board` du contrat API), un
composant d'affichage `display/Board.vue` qui reçoit les pièces en prop et
émet `move`, et la page d'accueil qui détient l'état et le bouton
« Réinitialiser ».

**Tech Stack:** Nuxt 4, Vue 3 (`<script setup lang="ts">`), Vitest 5 +
`@nuxt/test-utils` (environnement `nuxt`), `@vue/test-utils`, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-16-board-poc-design.md`

## Global Constraints

- Tout le code front est dans `screens/app/` ; les tests dans `screens/test/`.
- Toutes les commandes se lancent depuis `screens/`.
- Aucun backend, aucun appel API, aucune nouvelle dépendance.
- Aucune règle d'échecs : déplacement libre de n'importe quelle pièce vers
  n'importe quelle case ; case d'arrivée occupée → la pièce est capturée.
- Pas de Bouffon : seulement des pièces blanches (`w`) et noires (`b`).
- Format du plateau = schéma `Board` de `docs/openapi.yaml` : matrice 8×8 de
  codes `"wK"`, `"bP"`… (couleur `w|b` + `K Q R B N P`), `""` = case vide ;
  ligne 0 = rangée 8, colonne 0 = colonne a.
- Pièces en caractères Unicode : blancs ♔♕♖♗♘♙, noirs ♚♛♜♝♞♟.
- Blancs en bas ; coordonnées a–h sous le plateau, 8–1 à gauche.
- Pas de glisser-déposer, pas d'animation.
- Textes de l'interface en français ; commits en anglais, titre ≤ 50
  caractères, terminés par
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Branches : tâches 1–2 sur `feat/3-board-display` (issue #3, plateau) ;
  tâches 3–5 sur `feat/4-move-pieces` (issue #4, pièces), créée depuis
  `feat/3-board-display`.

## Review Focus

- Clic sur une case vide sans sélection : rien ne se passe, aucun `move`
  émis (test dans la tâche 4).
- Re-clic sur la pièce sélectionnée : désélection, aucun `move` émis
  (test dans la tâche 4).
- `movePiece` avec une case de départ vide, ou départ = arrivée : aucune
  pièce perdue, liste inchangée (test dans la tâche 3).
- `initialBoard()` / `movePiece()` ne doivent jamais partager ni muter
  d'état : sinon « Réinitialiser » ne remet pas la position après des
  captures (tests dans les tâches 3 et 5).
- Le pion noir ♟ (U+265F) s'affiche en emoji coloré sur certains
  systèmes (Android, iOS) : forcer la présentation texte avec U+FE0E
  (test dans la tâche 3).

### Task 3: Modèle des pièces

**Files:**

**Interfaces:**
- Consumes: `Square`, `FILES`, `RANKS`, `BoardFile`, `BoardRank` (tâche 1).
- Produces (dans `~/utils/pieces`) :
  - ``export type PieceCode = `${'w' | 'b'}${'K' | 'Q' | 'R' | 'B' | 'N' | 'P'}` ``
  - `export type Cell = PieceCode | ''`
  - `export type BoardMatrix = Cell[][]` — 8×8, ligne 0 = rangée 8,
    colonne 0 = colonne a (schéma `Board` du contrat).
  - `export function initialBoard(): BoardMatrix` — identique à l'exemple
    de `GET /boards/{id}` du contrat ; nouvelle matrice à chaque appel.
  - `export function cellAt(board: readonly (readonly Cell[])[], square: Square): Cell`
  - `export function movePiece(board: readonly (readonly Cell[])[], from: Square, to: Square): BoardMatrix`
    — ne mute jamais l'entrée. Place le code de `from` sur `to` (ce qui
    capture ce qui s'y trouvait) et vide `from`. Si `from` est vide ou
    `from === to`, renvoie une copie identique.
  - `export function pieceGlyph(code: PieceCode): string` — caractère
    Unicode suivi de `'\uFE0E'`.

```ts
import { describe, it, expect } from 'vitest'
import { initialBoard, cellAt, movePiece, pieceGlyph, type BoardMatrix } from '~/utils/pieces'

const pieceCount = (board: BoardMatrix) => board.flat().filter((cell) => cell !== '').length

describe('initialBoard', () => {
  it('matches the starting position example of the API contract', () => {
    expect(initialBoard()).toEqual([
      ['bR', 'bN', 'bB', 'bQ', 'bK', 'bB', 'bN', 'bR'],
      ['bP', 'bP', 'bP', 'bP', 'bP', 'bP', 'bP', 'bP'],
      ['', '', '', '', '', '', '', ''],
      ['', '', '', '', '', '', '', ''],
      ['', '', '', '', '', '', '', ''],
      ['', '', '', '', '', '', '', ''],
      ['wP', 'wP', 'wP', 'wP', 'wP', 'wP', 'wP', 'wP'],
      ['wR', 'wN', 'wB', 'wQ', 'wK', 'wB', 'wN', 'wR'],
    ])
  })

  it('returns a fresh, independent board each call', () => {
    const first = initialBoard()
    first[0]![0] = ''
    first[6]![4] = ''
    expect(initialBoard()[0]![0]).toBe('bR')
    expect(pieceCount(initialBoard())).toBe(32)
  })
})

describe('cellAt', () => {
  it('reads a square with row 0 = rank 8 and column 0 = file a', () => {
    const board = initialBoard()
    expect(cellAt(board, 'a8')).toBe('bR')
    expect(cellAt(board, 'd8')).toBe('bQ')
    expect(cellAt(board, 'e1')).toBe('wK')
    expect(cellAt(board, 'h1')).toBe('wR')
    expect(cellAt(board, 'e2')).toBe('wP')
    expect(cellAt(board, 'e4')).toBe('')
  })
})

describe('movePiece', () => {
  it('moves a piece to an empty square', () => {
    const after = movePiece(initialBoard(), 'e2', 'e4')
    expect(cellAt(after, 'e2')).toBe('')
    expect(cellAt(after, 'e4')).toBe('wP')
    expect(pieceCount(after)).toBe(32)
  })

  it('captures the piece on the target square, whatever its color', () => {
    const after = movePiece(initialBoard(), 'd1', 'd8')
    expect(pieceCount(after)).toBe(31)
    expect(cellAt(after, 'd8')).toBe('wQ')
    const own = movePiece(initialBoard(), 'a1', 'a2')
    expect(pieceCount(own)).toBe(31)
    expect(cellAt(own, 'a2')).toBe('wR')
  })

  it('does not mutate its input', () => {
    const before = initialBoard()
    movePiece(before, 'e2', 'e4')
    expect(before).toEqual(initialBoard())
  })

  it('keeps every piece when from is empty or equals to', () => {
    expect(movePiece(initialBoard(), 'e4', 'e5')).toEqual(initialBoard())
    expect(movePiece(initialBoard(), 'e2', 'e2')).toEqual(initialBoard())
  })
})

describe('pieceGlyph', () => {
  it('uses Unicode symbols forced to text presentation', () => {
    expect(pieceGlyph('wK')).toBe('♔︎')
    expect(pieceGlyph('bP')).toBe('♟︎')
  })
})
```
